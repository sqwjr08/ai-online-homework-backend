# 作业发布与状态：节点 09

本节点完善作业状态与截止规则，不接入真实 AI，也不完成节点 10 的提交唯一约束。

## 状态与接口

统一前缀 `/api/v1`。以下写接口仅允许班级所属教师或管理员，学生返回 403，未登录返回 401。

| 接口 | 规则 |
| --- | --- |
| POST /assignments | 创建 draft 或 published；默认 published，不能直接创建 archived |
| PATCH /assignments/{id} | 仅草稿，可部分修改 title、description、questions、due_at |
| POST /assignments/{id}/publish | draft -> published；锁题后生成完整快照并与状态一起写入 |
| POST /assignments/{id}/archive | draft/published -> archived；保留内容和提交，不物理删除 |
| GET /assignments/my?status=published | 可选 draft/published/archived 筛选，省略时返回自己可访问的状态 |

草稿编辑不能修改班级、状态、创建人、版本或快照；这些额外字段返回 422。空 PATCH、空白标题、显式 null 标题/题目列表也返回 422。标题去除首尾空白，长度 1 至 200；description/due_at 支持传 null 清空，省略则保持原值。

题目列表是完整替换，至少一道，顺序即题号；空列表、重复 ID、不存在或停用题目返回 400，其他教师的题目返回 403。替换成功后锁定新题，原题和失败操作留下的保守锁不自动解除。

发布后所有内容字段及截止时间固定，PATCH 返回 409。暂无延期、撤回发布、恢复归档、转移班级或删除入口；需要改版时创建新作业。顺序重复 publish/archive 请求返回 200，不重复生成快照或增加版本；已归档作业不能发布。归档班级阻止草稿编辑和发布，但允许归档其已有作业。重复发布仍受班级活动状态检查约束。

## 截止时间

- `due_at` 可省略或为 null，表示没有截止时间。
- 非空时间使用含时区的 ISO 8601，例如 `2030-01-01T20:00:00+08:00` 或 `2030-01-01T12:00:00Z`；无时区输入返回 422。
- 保存前统一为 UTC，并截断至 MongoDB 的毫秒精度；接口截止时间返回 UTC。旧 BSON 解码得到的无时区 datetime 按 UTC 解释，不按服务器本地时区解释。
- 草稿允许保存已过期时间，但正式发布以及直接创建 published 时，截止时间必须严格晚于检查时刻，否则返回 400。
- 提交时 `当前时间 >= due_at` 即截止，返回 400；同步评分结束、保存答案前再次检查。因此在截止前发起但评分完成时已经截止的请求也会被拒绝。先保存答案再异步评分属于节点 14。
- 到期不会自动归档，学生仍可读取本班已发布题面，但不能新提交。

## 可见范围与历史

教师按班级归属查看作业，管理员可查看全部。学生只可见当前所属班级的 published 作业；不能通过 status 筛选扩大范围，请求 draft/archived 列表得到空数组，相应详情和提交返回 404，跨班详情返回 403。

作业归档后保留已有提交。学生仍可通过已知提交 ID 读取本人的提交，未确认成绩隐藏；教师可继续确认成绩。学生题面不含参考答案或 rubric，见 [快照契约](assignment-snapshots.md)。班级归档与作业归档不同：班级归档保留已发布作业的历史读取规则，不自动归档班内作业。

归档不改写快照。归档草稿通过内部 `archived_from=draft` 保留 draft_preview 来源；已发布快照归档后仍为 snapshot，旧引用作业仍为 legacy_reference，不伪造历史内容。

## 并发与兼容边界

`Assignment.revision` 是服务端条件更新计数，不是快照格式版本。编辑、发布、归档以读取时的状态和 revision 做条件更新，成功时加一；旧记录缺少 revision 按 0 处理。竞争写入失败返回 409，客户端重新读取后重试，不能覆盖另一个请求已经保存的内容或把归档作业重新发布。顺序重试幂等不代表所有并发重试都返回 200。

发布将完整快照、snapshot_version 与 status 在作业单文档中一次写入；已有已发布快照不会因重复发布而刷新。未主动改动旧数据，不需要批量迁移。所有应用写入口必须遵循新协议，禁止混跑旧版本写同库。

这不是跨集合事务。班级归档、题目锁和提交保存仍是独立操作；提交保存前虽再次检查状态与截止时间，检查和写入之间仍有短暂竞态窗口。保存失败或竞争失败可能留下题目锁；损坏的旧引用/快照会返回 409，需要单独维护。节点 10 已补充 [提交唯一索引、答案校验和找回本人提交](submissions.md)，不改变上述跨集合边界。
