# 教师批改与学生结果：节点 11

用户已确认：**首次确认后锁定成绩，重复或并发确认返回 409**。不提供更正、重新打开或撤销成绩的功能与接口。本节点没有真实 AI 接入。

## 教师提交列表

`GET /api/v1/assignments/{assignment_id}/submissions`

仅班级所属教师或管理员可访问，学生 403，未登录 401，缺失作业/班级 404。作业或班级归档后仍可查看历史提交和进行首次确认。

| 参数 | 含义 |
| --- | --- |
| page | 默认 1，范围 1 至 1,000,000 |
| page_size | 默认 20，范围 1 至 100 |
| status | 可省略，或 pending_teacher_review / confirmed |

响应包含 `items / total / page / page_size / progress`。items 为教师视图，包含学生 ID、逐题答案、AI 草稿和最终结果；按 submitted_at、id 升序排列，便于优先处理较早提交。total 是筛选后的数量，越界页返回空 items。

progress 为当前作业全部提交的统计，不随状态筛选变化：

```json
{
  "submitted_count": 10,
  "pending_count": 3,
  "confirmed_count": 7
}
```

这些数字是已提交记录的批改进度，不是班级学生人数，也不表示未提交人数。使用同一次聚合的 facet 构造列表、筛选数量和进度；不包含其他作业提交。列表保留学生 ID，不附带独立学生搜索或未提交名单。

## 确认与校验

`POST /api/v1/submissions/{submission_id}/confirm-grade`

权限与上述列表一致。请求仍为 `grades` 数组，每项包含 question_id、final_score 和可选 final_comment。

- grades 至少一项；必须恰好覆盖提交中的全部题目，每题一次，顺序可以不同。重复、遗漏或多余题目返回 400。
- final_score 必须是非负有限 JSON 数值，最多两位小数；不接受字符串、布尔值、NaN、Infinity 或需要隐式四舍五入的精度，校验失败 422。
- 每题分数不能超过作业快照满分，超出返回 400；旧引用作业沿用显式引用兼容规则。题库当前内容不替代发布快照。
- 满分原有精度不变，例如满分 2.555 时最终分数最多可填 2.55，不会舍入到 2.56；没有顺便修改题库分值契约。
- 总分按已验证的逐题分数使用 Decimal 累加，再转换为可存储的有限数值；不接受客户端总分，溢出返回 400。
- final_comment 最多 1,000 字符，去掉首尾空白；省略、null 或纯空白保存为 null。**不自动回填 AI 评语**，教师可在确认时明确提交其认可的评语。
- 禁止额外请求字段。损坏的作业/提交题目对应关系、未发布的草稿、无效快照返回 409，不部分写入成绩。

全部校验完成后，以数据库中仍为 pending_teacher_review 为条件，一次写入答案最终分数/评语、总分、confirmed 状态、批改人和时间。只有一个并发请求可成功；其他请求返回 409，不覆盖赢家数据。已确认记录（包括此前版本确认的记录）也返回 409，管理员不能绕过。

正常请求顺序为身份/权限检查、已确认状态检查、业务校验和条件写入。请求模型本身不合法时 FastAPI 仍可先返回 422，不能据此认为成绩被解锁。所有写入需通过新版入口，直接数据库写入或旧程序不受该协议保护。

## 学生响应隔离

学生提交成功响应、按作业找回本人提交、按 submission_id 查看详情，均使用独立 StudentSubmissionRead：

- `view=student`，不包含 ai_total_score、ai_score、ai_comment；这些字段是不存在，不是 null。
- 待确认时逐题 final_score/final_comment、final_total_score、reviewed_by/reviewed_at 为 null，即使数据库中有旧的残留字段也不展示。
- 确认后返回最终分数和评语及批改元数据，保留本人答案和提交时间。历史查询规则不变，归档不会清除本人访问权限。
- 教师/管理员响应为 `view=teacher`，仍保留 AI 草稿以供审核；传入 `?view=teacher` 不能提升学生权限。

这是响应契约调整：前端不应继续读取学生响应中的 AI 字段。混合角色详情在 OpenAPI 中通过 view 区分模型，使用字段白名单防止回退到教师模型。已有已确认记录的最终评语不会被本节点追溯改写。
